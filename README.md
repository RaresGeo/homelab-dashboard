# Homelab Dashboard

A very simple and lightweight dashboard linking to all of my self hosted
services running on my homelab laptop ([NixOS](https://nixos.org/)).

🔗 **[Live site](https://kryllix.dedyn.io)**

## Philosophy

For once I wanted to escape the mad overengineering of frontend 
and have just static HTML, CSS and JavaScript. 
Even the `README.md` is simple :)
